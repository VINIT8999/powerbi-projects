# ✈️ Airline Flight Performance Analysis Dashboard

Comprehensive Power BI analytics project analyzing airline operations, revenue performance, and flight statistics across multiple carriers. Features interactive visualizations tracking **10 airlines**, **200+ destinations**, and **₹102 billion** in annual revenue with advanced DAX measures and data modeling.


---

## 🎯 Project Overview

This Power BI project delivers a comprehensive analysis of **airline flight performance** across multiple carriers, providing actionable insights into revenue generation, operational efficiency, and customer service metrics. The dashboard enables stakeholders to make data-driven decisions regarding route optimization, fleet management, and service improvements.

**Key Highlights:**
- 📈 **₹102 billion** in total annual revenue analyzed
- ✈️ **10 major airlines** performance comparison
- 🌍 **200+ destination airports** tracked
- 👥 **2 million** total employees across carriers
- 📊 **Multiple interactive dashboards** with drill-through capabilities
- 🔍 **Advanced DAX measures** for complex calculations
- 📱 **Responsive design** optimized for desktop and mobile viewing
---

## 🎯 Problem Statement

Airlines need to optimize their operations, maximize revenue, and improve customer satisfaction in an increasingly competitive market. This analysis addresses key challenges:

1. **Revenue Optimization**: Identifying top-performing routes and airlines
2. **Operational Efficiency**: Analyzing on-time performance and flight status
3. **Market Analysis**: Understanding competitive positioning across airlines
4. **Fleet Management**: Evaluating aircraft model performance and capacity utilization
5. **Route Planning**: Identifying profitable destinations and underperforming routes
6. **Customer Service**: Monitoring delays and cancellations to improve satisfaction

### Relationships
- **One-to-Many**: AirlineCompanies (1) → FlightData (*)
- **One-to-Many**: FlightData (1) → ON-TIME (*)
- Complex relationships between multiple dimension and fact tables

### Key DAX Measures Created
```DAX
Total Revenue = SUM(FlightData[Revenue])
Total Profit = SUM(DomesticProfitFirstClass[TotalProfit])
On-Time Percentage = DIVIDE([On-Time Flights], [Total Flights], 0)
Average Distance = AVERAGE(FlightData[Distance_km])
Market Share = DIVIDE([Airline Revenue], [Total Revenue], 0)
YoY Growth = ([Current Year Revenue] - [Previous Year Revenue]) / [Previous Year Revenue]
```
