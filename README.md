✈️ **Flight Company Performance Analysis Dashboard**

## 📌 Project Overview

This Power BI project presents an analytical dashboard designed to evaluate and compare the performance of multiple airline companies. It simulates a real-world airline analytics scenario by integrating operational, financial, and customer-related data to deliver clear, actionable business insights.

The dashboard answers key business questions such as:

* Which airlines generate the highest revenue and profit?
* How do domestic and international flights compare in profitability?
* What is the distribution of flight statuses (On-Time, Delayed, Cancelled)?
* Which cities and routes contribute the most to passenger traffic?

---

## 🎯 Objectives

* Analyze airline revenue, profit, and operational efficiency
* Compare airline performance across multiple KPIs
* Visualize trends using interactive Power BI visuals
* Demonstrate strong data modeling, DAX, and storytelling skills

---

## 🗂️ Dataset Description

The dataset represents **simulated airline industry data** structured for analytical reporting.

### Key Tables

* **AirlineCompanies** – Airline master data (Airline Name, Annual Revenue, Fleet Size, Global Ranking, Average Ticket Price, Employees)
* **FlightData** – Flight-level details (Aircraft Model, Destination, Distance, Cost, Flight Status)
* **ON_TIME** – Aggregated on-time performance data
* **DomesticProfitFirstClass** – Profit data for domestic first-class flights

### Key Metrics

* Revenue (Annual & Total)
* Profit per Year
* Passenger Count
* Flight Count
* Distance (KM)
* Ticket Price Range

---

## 🧩 Data Modeling

* Star-schema–like data structure
* One-to-many relationships between **AirlineCompanies** and **FlightData**
* Proper use of primary and foreign keys
* Optimized calculated columns and measures using DAX

## 📊 Dashboard Pages & Insights

### 1. Flight Company Performance Analysis Dashboard

**Insights:**

* Passenger distribution by city
* Revenue comparison across airlines
* Market share analysis
* Airline-wise ticket pricing, baggage allowance, meals, and total revenue

### 2. Airline Flight Performance Dashboard

**Insights:**

* Revenue ranking by airline
* Flight status distribution (On-Time, Delayed, Cancelled)

### 3. Decomposition Tree Analysis

**Purpose:**

* Drill-down analysis of Annual Revenue by:

  * Airline Name
  * Flight Type (Domestic / International)
  * Profit per Year
  * Distance
  * Flight Status

This enables root-cause analysis of revenue variations.

### 4. Summary & KPI Dashboard

* Airline-wise total profit
* Airline-wise total flights and revenue
* Executive-level performance snapshot
* Profit comparison: Domestic vs International flights
* KPI cards (Total Revenue, Total Profit, Airlines Count, Employees)
* Smart Narrative for automated insights
